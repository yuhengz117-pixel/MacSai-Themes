# Glass Care appearance

Follow-up to the original Native edition, requested to feel closer to
CleanMyMac. This replaces the Native appearance under the existing preference
key, so the installed local edition opens with the new design automatically.

- Compact dark navigation with six primary destinations and an All tools disclosure.
- Per-module gradient backgrounds and original code-drawn glass illustrations.
- Smart Care welcome panel with working Cleanup, Protection, and Performance links.
- Shared scanning welcome panels for System Junk and ModuleContainer modules.
- Original gradient mode remains selectable in Settings → Appearance.
- Deep/light behavior, upstream scans, result selection, and cleanup confirmations remain.

The reference is MacPaw's public product screenshots, not bundled assets:
https://macpaw.com/cleanmymac
All orb artwork is drawn in SwiftUI. No CleanMyMac marks or illustrations are shipped.

This is a local ad-hoc signed build, not an official MacPaw or Mac Sai release.

Validation: Apple Silicon release build and strict local code-signature check
passed. Inspected actual dark and light windows, opened the System Junk
welcome from navigation, and expanded All tools to confirm remaining modules
are reachable. No cleanup or maintenance operation was executed.
